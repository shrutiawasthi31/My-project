# LexReason

LexReason is a lightweight multi-page website concept for a legal intelligence platform.

## Pages

- `index.html`
- `platform.html`
- `practice-areas.html`
- `insights.html`
- `contact.html`

## Validation

Run:

```bash
npm test
```

This checks that the shared assets and cross-page navigation are present for the full site.

## Deployment

The repository includes a GitHub Actions workflow that validates and deploys the static site to GitHub Pages on pushes to `main`.
